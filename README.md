A deterministic program that writes the one-line excuse an AI agent gives its human for missing a deadline — it hit the deadline in a parallel tool call that never returned — to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
